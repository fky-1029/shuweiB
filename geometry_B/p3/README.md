# P3 水平指向误差数值分析

原始赛题：`problem/problem_B.pdf` Problem 3。运行 `.venv/bin/python -m geometry_B.p3.analysis --output-dir figures/<全新目录>`；默认使用 `figures/p3_output/`，输出目录必须为空或不存在，拒绝覆盖已有结果。`--quick` 使用 2 万样本作烟测，不替代正式验证。测试：`.venv/bin/python -m pytest -q geometry_B/p3`。

**模型约定**：名义指令误差是由估计车位计算的 `atan2` 方位减去真实方位；实际有效指向误差再加彼此独立的云台零偏与控制误差，并 wrap 到 [-π,π)。本题的概率指标使用后者。内部角度均为弧度，图表及题面角度为度。真实水平距离固定 40 m，估计位置减真实位置为定位误差。定位 x/y 各独立服从 N(0,(0.3+0.02s)²) m²，云台两项标准差分别为 0.8° 与 0.6°，且均独立。目标位置精确已知。

一阶传播使用雅可比 `(sin(theta)/40, -cos(theta)/40)` 和三项方差加和；`scipy.stats.norm.ppf(0.975)` 给出一阶概率边界。精确概率先在二维各向同性高斯密度中解析积去径向坐标，再对极角进行分段一维自适应积分；云台高斯的 wrap 通过平移正态 CDF 之和处理。`brentq` 求 0.95 根，执行单调性网格检查并记录代回残差。精确 a,b 可行域是 `a≥0, b≥0, a+80b≤精确定位标准差上界`；一阶相应上界单独列出。独立抽取四个坐标/角度随机量（对应三类物理误差），分别计算精确和一阶角差，使用 Wilson 双侧 95% 比例区间；同一场景的两种模型采用配对样本，不同场景使用不同种子。临界点使用两次独立百万样本验证。

生成 3 张 PNG 图及 1 份 JSON 明细。方差贡献率是各项一阶方差除以总方差，不是非线性误差份额。注意：临界概率由确定性积分确定，蒙特卡洛只作验证；二项比例区间不是临界距离的置信区间。极大定位标准差时高斯方位可能跨 wrap 切口，一阶近似不保证准确；本次只用于与精确模型对照。可从固定 `seed`、版本号、输入和样本数复现实验；完整运行不会触碰 P1/P2 文件。
