# P1（T1）结果说明卡

> 用途：供 C 整理进论文。本文区分观测质量主目标、离散部署时间结论与连续最优性，不将时间约束误写成加权目标。

- **模型名称/类型：**
  T1 车辆站位可观测性约束模型；在满足停车合法、有限三维视线无遮挡和云台仰角约束的站位中，以最大化水平观测质量 `Q=1/r` 为主目标。

- **核心公式（LaTeX）：**

  目标水平坐标及高度：
  \[
  (x_T,y_T,z_T)=\left(50+40\cos30^\circ,\;50+40\sin30^\circ,\;45\right)
  =(84.6410161514,70,45)\ \mathrm m.
  \]
  摄像头离地 `2 m`，目标与摄像头的高度差为 `\Delta h=43 m`。站位 `(x,y)` 到目标的水平距离和仰角为
  \[
  r=\sqrt{(x-x_T)^2+(y-y_T)^2},\qquad
  \theta=\operatorname{atan2}(43,r),\qquad Q=\frac{1}{r}.
  \]
  由 `\theta\le80^\circ` 得到
  \[
  r\ge r^*=\frac{43}{\tan80^\circ}=7.582060170463998\ \mathrm m.
  \]
  车辆圆盘须处于场地内且不与建筑投影相交；站位至目标的有限三维视线不得与建筑相交。上述可行性统一调用 `shared.geometry_interface.check_observation_feasibility()` 及其几何判定。

- **为什么这么建（一句话原理）：**
  `Q=1/r` 随距离减小而增大，因此先由仰角约束给出距离的解析下界，再以可行性见证检验该下界能否达到。

- **参数来源（题目给/自己定/数据估计 + 理由）：**
  T1 告警位置、场地和建筑、车辆半径 `1.5 m`、摄像头高度 `2 m`、云台范围等取自题目参数和 `shared/constants.py`；高度差 `43 m` 为目标高度减相机高度。理论见证坐标是分析构造值，并由项目公共接口复核。圆周扫描的 `1°` 步长是用于离散候选初筛的数值设置，并非题目规定或精度保证。

- **算法（名称、为什么选、关键参数、初始值、停止条件）：**
  1. **解析下界与可行见证：**由单调目标和仰角上限推导 `r*`；对构造点 `(80.00207316612234,75.99731976870402) m` 调用公共综合接口。该点通过三项可行性检查且达到理论距离下界，因此主目标最优值可达。
  2. **圆周离散扫描：**以 T1 水平投影为圆心，在半径 `r*` 上从 `0°` 到 `359°` 按 `1°` 取 360 点，逐点由公共接口检查。浮点临界角点保留原始判断；对规定的舍入临界情况只沿目标径向向外作机器精度级调整，再重新调用原接口，并限制半径偏差不超过 `1e-11 m`。最终 284 个数值采样点通过严格接口检查。此扫描不证明连续圆周上的部署时间全局最优。
  3. **离散部署时间比较：**对 284 个可行样本和五辆车的起点共 1420 个组合，计算直线行驶时间下界 `d/3` 与云台初次指向时间之和。无迭代算法、初始值或收敛停止条件；本步骤为有限枚举。对最小下界组合另检查整条直线路径的车辆圆盘避障及场地边界合法性。

- **结果数值（带单位）：**
  - 主目标最优距离：`r*=7.582060170463998 m`；见证点 `(80.00207316612234,75.99731976870402) m` 通过共享可行性接口，故 `Q*=1/r*≈0.131890 m⁻¹` 可达。
  - 1° 圆周扫描：360 个原始采样点；原始浮点判断有 262 点可行；对数值临界点按上述规则调整并复核后，共 284 点可行。调整是机器精度级近似，不声称每点精确位于数学圆周。
  - **离散部署时间最优组合：**V4 从 `(88,68) m` 前往圆周 260° 样本 `(83.32440521981547,62.53312836032199) m`。直线距离 `7.193599382312343 m`，恒速 `3 m/s` 的行驶时间 `2.397866460770781 s`；云台指向时间 `2.6666666666666687 s`；合计 `5.06453312743745 s`。
  - 该直线路径整段合法，建筑障碍和场地边界均无侵入；因直线距离是路径长度下界且直线路径可行，本组合的行驶时间下界可达到。它同时是 1420 组直线时间下界中的最小值（次小下界 `5.075423018365413 s`）。因此可证明它是**所列 284 个离散站位×五车组成的集合中的部署时间最优组合**。此结论依赖题设的恒速和云台时间模型。
  - 上述离散最优**不等于**连续圆周部署时间全局最优；1° 采样点之间未被穷尽或连续优化。

- **评价指标：**
  主目标评价量为观测质量 `Q=1/r`（`m⁻¹`），约束为停车合法、视线无遮挡和云台仰角合规。主目标最优值由理论下界与可行见证证明。部署时间仅用于在该主目标并列的圆周离散样本间作第二层比较；`30 s` 若作为行驶限制，应单独检查为可行性约束，不能与 `Q` 或时间加权成同一目标。本文所证的是给定离散集合内的时间最优，不是连续集合的时间最优。

- **图（文件名 + 每张图说明什么）：**
  - `figures/p1_t1_observable_region_0p5m.png`：T1 可观测区域的 `0.5 m` 网格采样结果；不是连续边界的精确表示。
  - `figures/p1_t1_circle_candidates_1deg.png`：叠加理论最优半径圆周、可行离散样本及 V4 260° 部署时间最优组合。图中圆周是离散采样的显示，背景可观测区域来自 `0.5 m` 网格。
  - `figures/p1_t1_distance_distribution_0p5m.png`、`figures/p1_t1_elevation_distribution_0p5m.png`：可行网格样本的水平距离和仰角分布。
  - 对应矢量图可用同名 `.svg` 文件。

- **验证/检验（怎么证明模型对）：**
  1. `r≥43/tan80°` 给出任意可行站位的距离下界；连续见证点通过公共综合接口并达到该下界，证明 `Q` 主目标最优值可达。
  2. 圆周候选用公共几何接口逐点复核；原始与舍入修正记录分别保存在 `figures/p1_t1_circle_candidates_1deg.csv`。
  3. 对 V4 候选直线路径检查整条线段的车辆圆盘与建筑、场地净空；路径合法，且直线距离达到行驶路径长度下界。
  4. 检查 `figures/p1_t1_vehicle_deployment_1deg.csv` 的全部 1420 组直线时间下界；其最小值由可达该下界的 V4 组合取得，故其为离散集合内全局最小实际部署时间。
  5. 运行 `.venv/bin/python -m unittest geometry_B.test_p1_circle_analysis -v`；项目完整 `geometry_B` 回归测试此前通过。若需论文定稿复核，请从项目根目录重新运行该命令。

- **本问结论一句话：**
  T1 的观测质量最优值由可行连续见证达到；在 1° 圆周扫描得到的 284 个可行站位与五辆车构成的离散集合内，V4 前往 260° 样本的 `5.06453312743745 s` 部署时间可证明最优，但连续圆周的部署时间全局最优尚未证明。
