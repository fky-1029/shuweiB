## 6. 可观测条件（站点合法性的三个约束，须同时满足）

1. **车辆几何约束**：车辆圆盘（半径 1.5 m）不越界、不侵入建筑。
2. **视线遮挡约束**：相机→目标的三维视线段不得被建筑遮挡（与建筑棱柱的**面/棱/顶点相切或接触也算遮挡**）。
3. **云台俯仰约束**：视线俯仰角 ∈ [−10°, 80°]。

> 关键几何关系（相机高 2 m，目标高 H，水平距离 r）：
> `俯仰角 φ = arctan((H − 2) / r)`，须满足 `−10° ≤ φ ≤ 80°`。

## 7. 单次双车交会观测的完整时序

对一辆从当前位置去往站点 s、观测目标 t 的车，时间轴为（单位均为 s）：

| 步骤 | 时长 |
|---|---|
| 1. 行驶 | `t_travel = 距离 / 3`（行驶中云台保持正东水平） |
| 2. 云台转向（停车后） | `t_slew = max(|Δpan|, |Δelev|) / 30` |
| 3. 同步观测 | `5`（**开始时刻 = 该目标两辆车各自“到达 + 转向”的较晚者**） |
| 4. 云台复位 | `t_reset = max(|pan|, |elev|) / 30`（已处于正东水平则 = 0） |
| 5. 出发下一任务 | 复位完成后立即 |

其中：`Δpan` 为从正东转到目标方位的水平转角，`Δelev` 为从水平转到目标俯仰角的转角。

## 8. 各问专属参数

### P2(1)
- 方位角测量误差：两车独立，服从 `N(0, (1°)²)`。
- 约束：每辆车从**初始位置**到所分配站点的行驶时间 ≤ 30 s。

### P3
- 车辆定位误差：累计行驶 s m 后，水平坐标误差独立零均值正态，标准差 `0.3 + 0.02s`（m）。
- 云台零位偏差：标准差 `0.8°`。
- 云台控制误差：标准差 `0.6°`。
- 三者相互独立，且与车辆定位误差独立；目标位置视为完全已知。
- 车辆到目标水平距离固定为 `40 m`。
- 精度要求：`P(|Δψ| ≤ 5°) ≥ 0.95`。

### P4
- 扰动发生时刻：`t = 5 s`。
- 新告警：θ ∈ [0°, 360°)，R ∈ [30, 50] m，H = 50 m，需 2 车。
- 单车故障：5 车中恰好 1 车故障，等概率。
- 通信中断：区间 `[5, t_rec]`，`t_rec ∈ (5, 30]` s；中断期间车辆继续原任务，恢复后才收到新调度指令。
- 评价窗口：`t ∈ [0, 60]` s。
- 指标：完成率 `η = k / N`（N=窗口内应观测告警总数含新告警，k=成功开始观测的告警数）；`t_last`=最晚观测开始时间（有告警无法在窗口内开始时取 60）。先比 η 高，再比 t_last 小。
