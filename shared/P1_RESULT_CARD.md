# P1（T1）结果说明卡

> 用途：交给 C 整理进论文。区分观测质量主目标、离散部署时间结论与连续最优性，不将时间约束误写成加权目标。

- **模型名称/类型：**
  T1 车辆站位可观测性约束模型；在满足停车合法、有限三维视线无遮挡和云台仰角约束的站位中，以最大化水平观测质量 `Q=1/r` 为主目标。

- **核心公式（LaTeX）：**
  \[
  (x_T,y_T,z_T)=\left(50+40\cos30^\circ,\;50+40\sin30^\circ,\;45\right)
  =(84.6410161514,70,45)\ \mathrm m.
  \]
  摄像头离地 `2 m`，目标与摄像头高度差 `\Delta h=43 m`。站位 `(x,y)` 的水平距离和仰角为
  \[
  r=\sqrt{(x-x_T)^2+(y-y_T)^2},\quad
  \theta=\operatorname{atan2}(43,r),\quad Q=\frac1r.
  \]
  由 `\theta\le80^\circ` 得
  \[
  r\ge r^*=\frac{43}{\tan80^\circ}=7.582060170463998\ \mathrm m.
  \]
  车辆圆盘须处于场地内且不与建筑投影相交；站位到目标的有限三维视线不得与建筑相交。可行性统一调用 `shared.geometry_interface.check_observation_feasibility()` 及其几何判定。

- **为什么这么建（一句话原理）：**
  `Q=1/r` 随距离减小而增大，因此先由仰角约束给出距离解析下界，再用可行见证检验下界是否达到。

- **参数来源（题目给/自己定/数据估计 + 理由）：**
  T1 告警位置、场地和建筑、车辆半径 `1.5 m`、摄像头高度 `2 m`、云台范围等来自题目与 `shared/constants.py`；高度差 `43 m` 为目标高度减相机高度。理论见证坐标由分析构造并经公共接口复核。圆周扫描 `1°` 步长是数值初筛设置，不是题目参数或连续最优保证。

- **算法（名称、为什么选、关键参数、初始值、停止条件）：**
  1. **解析下界与可行见证：**由单调目标和仰角上限推导 `r*`；对 `(80.00207316612234,75.99731976870402) m` 调用公共综合接口。该点通过三项约束且达到距离下界，证明主目标最优值可达。
  2. **圆周离散扫描：**以 T1 水平投影为圆心，在半径 `r*` 上按 `1°` 取 360 点，逐点由公共接口筛选。舍入临界情况只沿目标径向外移机器精度级距离后重新检查，半径偏差不超过 `1e-11 m`。最终 284 个数值采样点通过严格接口检查；这不证明连续部署时间最优。
  3. **离散部署时间比较：**对 284 个样本和五辆车共 1420 个组合，枚举直线行驶时间下界 `d/3` 加云台初次指向时间；对最小值组合进一步核查整条直线路径。无迭代、初始值或收敛条件。

- **结果数值（带单位）：**
  - 主目标距离 `r*=7.582060170463998 m`；连续见证点通过公共接口，故 `Q*=1/r*≈0.131890 m⁻¹` 可达。
  - 圆周采样 360 点，原始浮点判断 262 点可行；对规定临界点作机器精度级调整并复核后，284 点可行。调整点是理论圆周的数值近似。
  - **离散部署时间最优组合：**V4 从 `(88,68) m` 前往 260° 样本 `(83.32440521981547,62.53312836032199) m`。直线距离 `7.193599382312343 m`，行驶时间 `2.397866460770781 s`，云台指向时间 `2.6666666666666687 s`，合计 `5.06453312743745 s`。
  - 该直线路径合法；直线距离是路径长度下界且此路径可行，因此该组合达到时间下界。它也是 1420 组下界中的最小值，次小值为 `5.075423018365413 s`。所以它是该**离散集合**的部署时间最优组合；连续圆周时间最优尚未证明。

- **评价指标：**
  主目标为最大化 `Q=1/r`（`m⁻¹`）；停车、无遮挡和云台角范围为可行性约束。部署时间只用于主目标并列站位的第二层比较；若有 `30 s` 行驶上限，应作为独立约束，不与定位/观测质量加权。

- **图（文件名 + 每张图说明什么）：**
  - `figures/p1_observable_region.png`：T1 可观测区域的 `0.5 m` 网格采样论文优先图，不是连续边界精确图（旧路径 `figures/p1_t1_observable_region_0p5m.png` 内容相同）。
  - `figures/p1_t1_circle_candidates_1deg.png`：理论最优半径圆周、可行离散样本及 V4 260° 部署时间最优组合；背景可观测区域来自 `0.5 m` 网格。
  - `figures/p1_t1_distance_distribution_0p5m.png`、`figures/p1_t1_elevation_distribution_0p5m.png`：可行网格样本的距离与仰角分布；同名 `.svg` 为矢量版本。

- **验证/检验（怎么证明模型对）：**
  1. `r≥43/tan80°` 是任意可行站位的距离下界；连续见证通过公共综合接口且达到下界，证明 `Q` 主目标最优值可达。
  2. 圆周每个候选经公共接口复核，原始及浮点修正记录见 `figures/p1_t1_circle_candidates_1deg.csv`。
  3. V4 直线路径整段满足车辆圆盘避障与场地边界约束，并达到行驶路径长度下界。
  4. 全部 `284×5=1420` 组部署时间下界的最小值由此 V4 组合取得，故该组合为所定义离散集合的部署时间最优。
  5. 测试命令：`.venv/bin/python -m unittest geometry_B.test_p1_circle_analysis -v`。

- **本问结论一句话：**
  T1 的观测质量最优值由连续可行见证达到；在 1° 圆周扫描得到的 284 个可行站位与五辆车组成的离散集合内，V4 前往 260° 样本的 `5.06453312743745 s` 部署时间可证明最优，但连续圆周时间全局最优尚未证明。
