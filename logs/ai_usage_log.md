## 记录 ID：AI-004
- 使用者：B（江可萌）
- 日期：2024-11-20
- 工具及版本/型号：Claude Code (Claude Opus 5.5)
- 开发机构/公司与版本发布日期：Anthropic / 2024
- 用途与对应问题：**目标坐标转换公式修正** - 修正极坐标到笛卡尔坐标的转换逻辑
- 关键提示词：检查方位角转换公式、核对 PDF 原文、修正坐标计算、标记待人工确认事项
- 输出要点：
  1. **发现问题**：AI-003 中的坐标转换采用了错误的公式
     - 错误：x = 50 + R·sin(θ), y = 50 + R·cos(θ)（通过 90°-θ 转换导致）
     - 正确：x = 50 + R·cos(θ), y = 50 + R·sin(θ)
  2. **PDF 分析**：题目仅给出"方位角"，未明确说明：
     - 起始方向（0°指向哪里）
     - 旋转方向（顺时针/逆时针）
     - 坐标系定义（x/y轴方向）
  3. **修正内容**：
     - 简化转换公式为直接使用：x = 50 + R·cos(θ), y = 50 + R·sin(θ)
     - 坐标修正：T1 (70.00,84.64) → (84.64,70.00)，T2/T3 同理
     - 在代码中标记 "⚠️ 待人工确认：PDF 未明确方位角定义"
  4. 更新 test_parameters.py 的验证逻辑和警告信息
  5. 测试通过
- 实际采纳部分：队员发现坐标疑问并提供期望值，AI 执行修正
- 队员如何独立核查与修改：
  1. 队员发现输出坐标与期望不符
  2. 队员指出应使用 x=50+R·cos(θ), y=50+R·sin(θ)
  3. AI 修正后运行测试验证
  4. **待人工确认**：方位角的实际定义需结合题目上下文或联系出题方确认
- 涉及文件、Commit、论文位置：
  - shared/constants.py（修正转换函数）
  - shared/test_parameters.py（更新测试和警告）

  - 未执行 git commit
